# AI Feedback and Learning

## Purpose

Max improves through recorded feedback and measured outcomes without silently changing client facts, active SOPs, permissions, or safety rules.

## What Max records

For meaningful AI work, record:

- Client
- Task
- Input snapshot
- Relevant facts
- SOP versions
- Skill versions
- Prompt version
- Provider
- Model role
- Output
- Human edits when available
- Approval or rejection
- Rejection reason
- Verification result
- Later measured outcome when available

Trivial acknowledgments do not require an AI learning record.

## Rejections and corrections

Rejected outputs remain visible. Corrections create new versions.

Repeated corrections may be grouped into a pattern such as:

- Wrong tone
- Unsupported claim
- Missing keyword
- Incorrect client fact
- Poor layout instruction
- Missing evidence
- Excessive cost

## Proposed improvements

Max may propose changes to:

- SOPs
- Skills
- Templates
- Checklists
- Prompts
- Model routing

Every proposed change remains `proposed` until tested and approved.

Max must not activate an improvement automatically.

## Evaluation before activation

A proposed improvement must:

1. Explain the reason.
2. Identify affected workflows.
3. Be tested against representative prior examples.
4. Preserve client separation and factual rules.
5. Be reviewed by the agency owner or authorized team member.
6. Receive a new version number.
7. Become active only after approval.

Previous active versions remain available for rollback.

## Privacy and cross-client learning

Max may learn generalized patterns from work, but must not copy one client's private facts, content, credentials, or assets into another client's workflow.

AI providers receive only task-relevant, redacted context. Provider retention and training terms should be checked before enabling a provider for client data.

## Measuring improvement

Track when practical:

- Approval rate
- Rejection rate
- Correction rate
- Verification success
- Failure rate
- Cost per task
- Time to completion
- Later measured outcome

Successful output is not considered a learning success until it is approved or verified when applicable.

## Budget

Learning evaluations must respect the $30 target and $50 hard monthly AI maximum. Use DeepSeek Flash for routine evaluation and stronger models only for difficult comparisons.

## Final checklist

- Output record saved?
- Human corrections preserved?
- Rejection reason recorded?
- Pattern identified honestly?
- Proposed improvement versioned?
- Prior examples tested?
- Client data separated?
- Provider privacy considered?
- Owner approval recorded?
- Budget respected?
