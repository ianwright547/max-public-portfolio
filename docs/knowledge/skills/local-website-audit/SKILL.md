# Local website audit skill

## Purpose

Use this skill when Max must inspect a local business website, diagnose problems, collect evidence, classify pages, prioritize corrections, or produce a website audit report.

This skill coordinates the full audit. It does not replace the focused Local SEO SOPs.

## Trigger conditions

Load this skill for requests involving:

- website audit
- site audit
- technical audit
- content audit
- page inventory
- index audit
- crawl audit
- local landing-page audit
- internal-link audit
- schema audit
- why pages are not indexed
- why local pages are not performing
- what website work should be completed first

## Minimum inputs

- approved business identity
- domain
- target location
- approved services
- approved service areas
- current website access
- crawl or URL inventory
- Search Console property when available
- analytics and conversion source when available
- audit goal
- audit date
- approval level

If access or data is missing, continue with the available evidence and state the limitation.

## Audit boundaries

A website audit may identify:

- technical barriers
- page gaps
- duplicate targeting
- weak intent matching
- unsupported claims
- internal-link problems
- local fact conflicts
- schema problems
- Search Console patterns
- content that should be improved, merged, redirected, removed, or retained

A website audit must not:

- invent a crawl result
- invent Search Console data
- claim a page is indexed without evidence
- claim a ranking without a measured source
- recommend deleting content based only on low traffic
- treat a tool score as a business result
- publish or change the site without approval
- promise a ranking or timeline

## Required output

Produce:

- audit scope
- data sources
- limitations
- page inventory
- priority findings
- evidence for every material finding
- action recommendation
- effort and risk
- approval need
- verification method
- prioritized execution order

## Completion standard

The audit is complete when:

- the domain and client facts were confirmed
- the important URL inventory was reviewed
- findings contain evidence
- technical and content findings are separated
- local facts were checked
- page actions were assigned
- recommendations are prioritized
- unsupported claims were removed
- the final report passed the Human Writing SOP
