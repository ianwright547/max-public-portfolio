# Multi-location Local SEO skill

## Purpose

Use this skill when one brand has several eligible locations, franchises, branches, offices, practitioners, or service operations that must be managed without mixing facts between locations.

## Trigger conditions

Load this skill for:

- multi-location SEO
- franchise SEO
- several Google Business Profiles
- location rollups
- location openings or closures
- location moves
- duplicate location content
- location-specific reporting
- category consistency across locations
- shared and local content rules
- several service areas under one brand

## Required inputs

- brand record
- location roster
- eligibility evidence per location
- profile identifier per location
- approved NAP per location
- categories and services per location
- location page per location
- phone routing
- hours
- service areas
- local approvers
- reporting sources

## Core rule

Never copy one location's facts, reviews, staff, hours, phone number, service availability, or results into another location without approval and evidence.

## Completion standard

The workflow is complete when the brand record and every location record remain separate, location eligibility is supported, public records align, reporting can be separated by location, and rollups show how totals were calculated.
