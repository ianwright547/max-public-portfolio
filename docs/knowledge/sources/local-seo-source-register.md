# Local SEO source register

## Purpose

This file records the source hierarchy behind the Local SEO knowledge pack.

Official platform guidance controls policy and product definitions. Practitioner material can contribute workflows, examples, and test ideas, but it cannot override official policy or create guarantees.

## User-provided transcripts

Use for:

- core page and service coverage ideas
- title, H1, and opening-copy emphasis
- internal link hierarchy
- technical audit prompts
- examples of local market review
- blog quality and traffic-intent discussion
- schema as a clarity tool
- separating relevant local demand from unrelated traffic

Limitations:

- speaker claims are not automatically verified
- case results do not create universal expectations
- sales language is not methodology
- precise traffic-share, ranking-factor, conversion, and timing claims require evidence
- instructions to eliminate blogs do not apply to this system
- blog posts remain approved when they serve intent and customer value
- claims about AI crawlers and llms.txt must be labeled as uncertain or experimental

### Universal Human Writing SOP

## Review schedule

Review official platform sources:

- before high-risk profile changes
- before changing service-area or eligibility rules
- before updating review-request rules
- before using new structured data features
- at least quarterly for the maintained knowledge version

Record all changes in a new version.
