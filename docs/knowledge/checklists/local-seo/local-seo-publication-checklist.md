# Local SEO publication checklist

Use this checklist before publishing or submitting any page, blog post, profile field, profile post, review reply, citation, schema change, redirect, or index instruction.

## Artifact identity

- [ ] Client recorded
- [ ] Location recorded
- [ ] Artifact type recorded
- [ ] Destination recorded
- [ ] Version recorded
- [ ] Author recorded
- [ ] Reviewer recorded
- [ ] Approval record attached

## Facts

- [ ] Business name matches approved record
- [ ] Address or hidden-address status is correct
- [ ] Phone is correct
- [ ] Website is correct
- [ ] Hours are correct
- [ ] Services are approved
- [ ] Service areas are approved
- [ ] Prices are approved
- [ ] Qualifications are approved
- [ ] Guarantees are approved and accurately limited
- [ ] Proof is traceable
- [ ] No customer result is invented
- [ ] No ranking is invented
- [ ] No testimonial is invented

## Local safety

- [ ] No fake location
- [ ] No false office language
- [ ] No fake review
- [ ] No review gating
- [ ] No prohibited incentive
- [ ] No keyword-stuffed business name
- [ ] No keyword-stuffed copy
- [ ] No city list created only for rankings
- [ ] No doorway-page pattern
- [ ] No misleading business description
- [ ] No hidden private address
- [ ] No link scheme

## Search intent and usefulness

- [ ] Primary intent is documented
- [ ] The artifact answers that intent
- [ ] The call to action is accurate
- [ ] The artifact has a reason to exist
- [ ] An existing page was considered before creating a new page
- [ ] Blog content serves a real customer need
- [ ] Local details are real
- [ ] Content does not rely on filler

## Page checks

- [ ] Title is accurate
- [ ] H1 is clear
- [ ] Opening copy identifies the need and next step
- [ ] Headings match the content
- [ ] Internal links are useful
- [ ] Internal links work
- [ ] External links are trustworthy
- [ ] Metadata is accurate
- [ ] Image alt text describes the asset
- [ ] Claims have sources
- [ ] No placeholders remain
- [ ] No duplicate target exists
- [ ] Canonical is correct
- [ ] Index directive is correct
- [ ] Status code is correct
- [ ] Sitemap impact is handled

## Google Business Profile checks

- [ ] Field follows current Google policy
- [ ] Category is valid
- [ ] Service is real
- [ ] Description contains no prohibited content
- [ ] Hours reflect real availability
- [ ] Service area is accurate
- [ ] Post destination works
- [ ] Phone and website were tested
- [ ] Before snapshot stored
- [ ] Rollback value stored

## Review response checks

- [ ] Reviewer and location match
- [ ] Response protects privacy
- [ ] Response does not argue
- [ ] Response does not confirm protected information
- [ ] Response makes no unsupported promise
- [ ] Serious issue was escalated
- [ ] Approval is recorded
- [ ] Response passed the Human Writing SOP

## Citation checks

- [ ] Existing listing checked before creating a new one
- [ ] Listing owner is known
- [ ] NAP matches approved identity
- [ ] No fake address
- [ ] No duplicate is created
- [ ] Platform is legitimate
- [ ] Submission confirmation will be stored
- [ ] Later verification is scheduled

## Structured data checks

- [ ] Markup matches visible facts
- [ ] Most specific appropriate type used
- [ ] Stable identifier used
- [ ] Public address handling is correct
- [ ] Hours are accurate
- [ ] Area served is accurate
- [ ] Ratings and reviews are supported
- [ ] No private information is exposed
- [ ] Rich Results Test passed
- [ ] Schema Markup Validator passed
- [ ] No rich-result or ranking guarantee is made

## Human writing check

- [ ] Universal Human Writing SOP loaded
- [ ] Approved voice used
- [ ] Generic filler removed
- [ ] Unsupported praise removed
- [ ] Keyword repetition removed
- [ ] Sentence rhythm sounds natural
- [ ] Facts were preserved
- [ ] No em dashes
- [ ] No chatbot preamble
- [ ] No generic closing added

## Verification plan

- [ ] Live destination identified
- [ ] Verification method defined
- [ ] Evidence format defined
- [ ] Verification owner defined
- [ ] Verification time defined
- [ ] Rollback or correction method defined

## Final approval

- [ ] Proposed
- [ ] Approved
- [ ] Executed
- [ ] Verified
- [ ] Evidence stored
