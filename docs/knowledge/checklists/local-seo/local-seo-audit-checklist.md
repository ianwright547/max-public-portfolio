# Local SEO audit checklist

## Audit record

- [ ] Client ID recorded
- [ ] Location ID recorded
- [ ] Auditor recorded
- [ ] Audit date recorded
- [ ] Scope recorded
- [ ] Data sources recorded
- [ ] Approval level recorded
- [ ] Prior audit located
- [ ] Known recent changes recorded
- [ ] Mock, manual, imported, modeled, and live data labeled

## 1. Approved business facts

- [ ] Approved business name confirmed
- [ ] Business type confirmed
- [ ] Address visibility confirmed
- [ ] Primary phone confirmed
- [ ] Website confirmed
- [ ] Hours confirmed
- [ ] Services confirmed
- [ ] Service areas confirmed
- [ ] Excluded areas confirmed
- [ ] Licenses and qualifications confirmed
- [ ] Approved differentiators confirmed
- [ ] Prohibited claims recorded
- [ ] No fake location is implied

## 2. Local keyword research

- [ ] Seed list comes from approved services
- [ ] Customer language included
- [ ] Explicit local queries researched
- [ ] Implicit local intent checked
- [ ] Near-me queries classified correctly
- [ ] Problem and symptom queries included
- [ ] Emergency queries match real availability
- [ ] Cost and qualification queries considered
- [ ] Informational and blog opportunities considered
- [ ] Tool, place, date, and settings recorded
- [ ] No search volume invented
- [ ] Keywords clustered by intent and meaning
- [ ] One phrase was not mapped to one page automatically
- [ ] Priority scoring documented

## 3. Search intent and page mapping

- [ ] Each cluster has a primary intent
- [ ] Each cluster has an assigned asset
- [ ] Existing pages reviewed before recommending new pages
- [ ] Overlapping pages identified
- [ ] Missing pages identified
- [ ] Blog posts retained where intent supports them
- [ ] Near-me phrases are not stuffed into copy
- [ ] No doorway-page plan exists
- [ ] No unsupported ranking forecast exists

## 4. Service-area targeting

- [ ] Actual operational coverage confirmed
- [ ] Primary areas identified
- [ ] Secondary areas identified
- [ ] Limited areas identified
- [ ] Excluded areas identified
- [ ] Drive time considered
- [ ] Dispatch capacity considered
- [ ] Licensing considered
- [ ] Travel fees considered
- [ ] Emergency coverage considered
- [ ] Service areas do not imply fake offices
- [ ] GBP service areas are accurate
- [ ] Current Google service-area limits checked
- [ ] Ranking radius is not guaranteed

## 5. Google Business Profile

### Eligibility

- [ ] Profile is eligible
- [ ] Ownership is known
- [ ] Verification status confirmed
- [ ] Storefront, service-area, or hybrid classification is correct
- [ ] Address visibility follows actual customer access
- [ ] No mailbox or unstaffed office is used
- [ ] One profile per eligible operation
- [ ] Duplicate profiles checked

### Business information

- [ ] Name matches the real-world name
- [ ] No name keyword stuffing
- [ ] Address or hidden-address status is correct
- [ ] Map pin checked
- [ ] Phone reaches the correct business
- [ ] Website represents the same business
- [ ] Hours are accurate
- [ ] Holiday hours are maintained
- [ ] Attributes are accurate
- [ ] Description is honest and useful
- [ ] Description contains no links or misleading promotions
- [ ] No unsupported guarantee appears

### Categories and services

- [ ] Primary category is specific and accurate
- [ ] Fewest useful categories are used
- [ ] Secondary categories are legitimate
- [ ] Services match real operations
- [ ] Duplicate services removed
- [ ] Service names are not stuffed with places
- [ ] Service descriptions use approved facts
- [ ] Important services map to website pages

### Photos and other assets

- [ ] Real assets are available
- [ ] Rights and permissions are recorded
- [ ] Storefront identification is accurate
- [ ] Team assets are current
- [ ] Work assets show real work
- [ ] Before-and-after sets are accurate
- [ ] No stock asset is presented as completed work
- [ ] No private customer information is visible
- [ ] No false location metadata is used
- [ ] No ranking claim is attached to metadata

### Posts and questions

- [ ] Recent posts reviewed
- [ ] Post claims verified
- [ ] Post links tested
- [ ] Questions monitored
- [ ] Answers are accurate
- [ ] Business does not pose as a customer
- [ ] Approval workflow exists

## 6. NAP and citations

- [ ] Canonical identity record exists
- [ ] Prior names recorded
- [ ] Prior addresses recorded
- [ ] Prior phone numbers recorded
- [ ] Core platforms checked
- [ ] Industry sources checked
- [ ] Local sources checked
- [ ] Material name errors found
- [ ] Old address errors found
- [ ] Wrong phone errors found
- [ ] Wrong website errors found
- [ ] Duplicate listings found
- [ ] Private address exposure checked
- [ ] Minor formatting issues separated from material errors
- [ ] Correction priority documented
- [ ] Login ownership recorded
- [ ] No fake citation is proposed
- [ ] No low-quality bulk submission is proposed

## 7. Reviews

- [ ] Total reviews recorded by platform
- [ ] Rating recorded
- [ ] New reviews by period recorded
- [ ] Response rate recorded
- [ ] Response time recorded
- [ ] Competitor comparison labeled as observation
- [ ] Review request process reviewed
- [ ] Requests ask for honest feedback
- [ ] No review gating
- [ ] No incentives tied to reviews
- [ ] No staff or family reviews
- [ ] No suggested keywords or rating
- [ ] Negative response escalation exists
- [ ] Privacy rules exist
- [ ] Suspected policy violations documented
- [ ] Negative reviews are not labeled fake without evidence
- [ ] No claim that a review caused ranking movement

## 8. Local relationships and links

- [ ] Existing local links reviewed
- [ ] Chambers and associations reviewed
- [ ] Industry directories reviewed
- [ ] Partners and suppliers reviewed
- [ ] Community relationships reviewed
- [ ] Sponsorships are real
- [ ] Paid relationships recorded
- [ ] Spammy links identified
- [ ] No link scheme proposed
- [ ] Outreach requires approval
- [ ] Live links will be verified

## 9. Website local signals

- [ ] Homepage or GBP landing page purpose is clear
- [ ] Business, service, place, and next action appear early
- [ ] Title is specific
- [ ] H1 is clear
- [ ] Opening copy serves the visitor
- [ ] Approved NAP or service-area statement appears
- [ ] Main services are linked
- [ ] Main places are linked
- [ ] Proof is traceable
- [ ] No unsupported superlatives
- [ ] No keyword stuffing
- [ ] No fake location language
- [ ] Human Writing SOP is required

## 10. Service, location, and blog pages

- [ ] Priority services have useful pages
- [ ] Physical location pages represent real locations
- [ ] Service-area pages do not imply offices
- [ ] Service and place pages have unique value
- [ ] City-swapped duplicates identified
- [ ] Blogs have defined intent
- [ ] Blogs support a service, place, or customer need
- [ ] Weak blog posts reviewed for refresh, merge, or removal
- [ ] Backlinks and conversions checked before deletion
- [ ] Internal links are mapped
- [ ] Orphan pages identified
- [ ] Broken links identified
- [ ] Titles and H1s are unique and accurate
- [ ] No arbitrary word-count rule is used

## 11. Internal linking

- [ ] Site hierarchy documented
- [ ] Priority pages receive relevant links
- [ ] Blog posts link to related services
- [ ] Service pages link to useful support content
- [ ] Location pages link to available services
- [ ] Breadcrumbs checked
- [ ] Anchor text is natural
- [ ] Exact-match anchor repetition checked
- [ ] Every link does not appear on every page
- [ ] Redirecting internal links identified
- [ ] Broken links identified

## 12. Local structured data

- [ ] Current markup detected in rendered output
- [ ] LocalBusiness subtype is appropriate
- [ ] Stable identifiers used
- [ ] Name matches approved facts
- [ ] Phone matches approved facts
- [ ] Public address handling is correct
- [ ] Hours are accurate
- [ ] Area served is accurate
- [ ] sameAs links are controlled
- [ ] Location entities are unique
- [ ] Service markup matches visible services
- [ ] Review markup is supported and eligible
- [ ] No private address is exposed
- [ ] No invented rating or review
- [ ] Rich Results Test completed
- [ ] Schema Markup Validator completed
- [ ] No ranking guarantee is made

## 13. Crawl and indexing

- [ ] Important pages return `200`
- [ ] Removed pages return a correct status
- [ ] Redirect chains checked
- [ ] Soft 404s checked
- [ ] Robots.txt checked
- [ ] Production is not blocked
- [ ] Index directives checked
- [ ] Canonicals checked
- [ ] Preferred host and protocol checked
- [ ] XML sitemap checked
- [ ] Sitemap contains canonical indexable URLs
- [ ] Internal links use canonical URLs
- [ ] Raw content checked
- [ ] Rendered content checked
- [ ] Important content is accessible
- [ ] URL Inspection planned or completed
- [ ] llms.txt, if present, is labeled experimental

## 14. Search Console

- [ ] Correct property selected
- [ ] Exact dates recorded
- [ ] Last complete date recorded
- [ ] Preliminary data handled
- [ ] Previous period compared
- [ ] Year-over-year comparison considered
- [ ] Branded and non-branded separated
- [ ] Commercial and informational separated
- [ ] Query groups documented
- [ ] Page groups documented
- [ ] Device differences checked
- [ ] Country differences checked
- [ ] Canonical aggregation considered
- [ ] Omitted query limitations stated
- [ ] Organic Search is separated from Maps
- [ ] Average position is not reported as an exact rank
- [ ] Clicks are not reported as leads
- [ ] No causation is claimed without evidence

## 15. Geogrid and ranking data

- [ ] Keyword recorded
- [ ] Date recorded
- [ ] Grid size recorded
- [ ] Radius or spacing recorded
- [ ] Center point recorded
- [ ] Provider recorded
- [ ] Maximum tracked position recorded
- [ ] Settings match prior comparison
- [ ] Strong and weak zones described
- [ ] Competitor data labeled as observation
- [ ] No single point is called the universal rank
- [ ] No visibility estimate is called actual leads
- [ ] Ranking limitations are stated

## 16. Website audit control

- [ ] Audit type recorded
- [ ] Domain variants tested
- [ ] Canonical host recorded
- [ ] URL inventory assembled from more than one source when available
- [ ] Every important URL has a page type
- [ ] Priority pages reviewed manually
- [ ] Crawl findings contain affected URLs
- [ ] Search Console findings use exact dates
- [ ] Page actions assigned
- [ ] No page is removed based only on low traffic
- [ ] Backlinks checked before removal
- [ ] Conversions checked before removal
- [ ] Assisted conversions considered
- [ ] Replacement destination confirmed
- [ ] Mobile access and conversion paths tested
- [ ] Audit limitations recorded
- [ ] Website audit report template used

## 17. Competitor analysis

- [ ] Market and search locations recorded
- [ ] Query set recorded
- [ ] Search date recorded
- [ ] Map and organic competitors separated
- [ ] Direct competitors separated from directories and marketplaces
- [ ] Competitor selection reason recorded
- [ ] More than one query or point checked when relevant
- [ ] Profile observations recorded
- [ ] Website coverage compared
- [ ] Review observations recorded
- [ ] Citation and local-authority observations recorded
- [ ] Technical observations recorded
- [ ] Client-ineligible services excluded
- [ ] Competitor text was not copied
- [ ] Policy violations were not copied
- [ ] No competitor tactic was stated as a confirmed cause
- [ ] Suspected spam uses neutral language and evidence
- [ ] Recommendations fit the client's real services and locations
- [ ] Measurement plan included

## 18. Content brief control

- [ ] Page job stated
- [ ] Page type selected
- [ ] Primary intent recorded
- [ ] Target reader recorded
- [ ] Approved service recorded
- [ ] Approved place recorded
- [ ] Keyword cluster recorded
- [ ] Required facts recorded
- [ ] Missing facts marked
- [ ] Proof recorded with source
- [ ] Local details recorded with source
- [ ] Internal links into the page recorded
- [ ] Internal links from the page recorded
- [ ] Call to action recorded
- [ ] Structured data needs recorded
- [ ] Prohibited claims recorded
- [ ] Human Writing SOP required
- [ ] Publication checklist required
- [ ] No arbitrary word-count requirement
- [ ] No exact-match repetition requirement

## 19. Multi-location control

- [ ] Brand record exists
- [ ] Location roster exists
- [ ] Stable location IDs used
- [ ] Eligibility confirmed per location
- [ ] Planned locations are not presented as open
- [ ] Profile identifier recorded per location
- [ ] NAP recorded per location
- [ ] Phone routing tested per location
- [ ] Hours confirmed per location
- [ ] Categories confirmed per location
- [ ] Services confirmed per location
- [ ] Location page recorded per location
- [ ] Local proof belongs to the correct location
- [ ] Reviews stay with the correct location
- [ ] Structured data uses separate location entities
- [ ] Citations stay location-specific
- [ ] Shared and local facts are separated
- [ ] Rollup method documented
- [ ] Missing location data stated
- [ ] Open, move, closure, and duplicate status recorded
- [ ] No cross-location fact contamination

## 20. Findings

Every finding includes:

- [ ] finding ID
- [ ] issue
- [ ] evidence
- [ ] source
- [ ] affected record or URL
- [ ] severity
- [ ] confidence
- [ ] evidence class
- [ ] recommended action
- [ ] approval requirement
- [ ] verification method
- [ ] rollback or correction plan
- [ ] owner
- [ ] target date

## 21. Final safety check

- [ ] No fake reviews
- [ ] No fake locations
- [ ] No keyword stuffing
- [ ] No unsupported guarantees
- [ ] No invented rankings
- [ ] No invented customer results
- [ ] No misleading business descriptions
- [ ] No invented services or credentials
- [ ] No false completion claim
- [ ] No em dashes
- [ ] No prohibited practice is hidden as an experiment
