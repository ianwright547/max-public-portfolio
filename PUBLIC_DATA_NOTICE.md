This repository is a recruiter-facing portfolio copy of Max. All client names, domains, IDs, provider responses, and examples are dummy data. No production database, Slack history, provider token, private client manifest, or live report belongs in this copy.

Integrations are shown as interfaces and guarded workflows. To run them against a real account, configure the provider credentials in a private environment and follow the authorization and verification checks documented in the project.
